# FUNUNKUL-STRIKE
FUNUNKUL STRIKE — динамичный офлайн-шутер с кубическими персонажами, 8 уникальными картами и 8 игровыми режимами. Выбирай режим, сражайся с противниками под управлением игры, открывай и используй разные скины. Играй самостоятельно без подключения к интернету. Погрузись в мир перестрелок и стань лучшим бойцом!
